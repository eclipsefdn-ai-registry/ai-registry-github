> **Inferred vendor repository.** This repo is maintained by the [AI Registry](https://github.com/eclipsefdn-ai-registry/ai-registry-core) project, not by GitHub. It pre-seeds the registry with GitHub's official MCP server and one first-party skill.
>
> *This entry is based solely on information published through GitHub's official public channels. GitHub has not endorsed, approved or validated this listing, and is not necessarily participating in the AI Registry.*

## What this repo contains

**MCP server**: [`github/github-mcp-server`](https://github.com/github/github-mcp-server) — "GitHub's official MCP Server" per its own repo description, owned by the verified `github` GitHub org, and live in the official MCP registry as `io.github.github/github-mcp-server`. Registry-listed, so no `metadata` fallback is needed. A generic `config` (remote `http`, `https://api.githubcopilot.com/mcp/` with a bearer-token header) is included anyway — the server's own README documents this remote endpoint as the recommended, host-agnostic connection method (VS Code, Claude Desktop, Cursor, Windsurf, Copilot CLI, Codex, etc. all connect the same way), so it doubles as the canonical config other vendors' `installConfigs` entries for this same `serverId` can request via `"config": "derived"` instead of repeating it.

**Agent Skill**: `spark-app-template`, from [`github/copilot-plugins`](https://github.com/github/copilot-plugins) at `plugins/spark/skills/spark-app-template`. `copilot-plugins` is GitHub's own marketplace repo (owned by `github`, described in its README as "the official GitHub Copilot plugins collection", `marketplace.json` owner is `GitHub <copilot@github.com>`). Most of its bundled plugins are explicitly attributed to Microsoft in that same `marketplace.json` (`workiq`, `fabric-*`, `power-*`, `cpp-language-server`, `build-perf-cpp` — the last one authored by two named Microsoft engineers even though it lives in this repo). The `spark` entry carries no such third-party author, its content matches [GitHub Spark](https://github.com/features/spark) (GitHub's own AI app-building product), and its commit history shows it was authored/reviewed directly by GitHub staff (e.g. `JasonEtco`, whose public profile lists `company: GitHub`) committing straight to `main`. On that basis it's included; `build-performance-analysis`, the other skill in this repo (nested under the Microsoft-attributed `build-perf-cpp` plugin), is excluded.

**No Agent Plugin approval is included**: no agent-plugins.org-conformant plugin (`plugin.json` manifest) was found published by GitHub. GitHub does ship `plugin.json` files that look like agent-plugins.org manifests — e.g. [`github/copilot-advanced-security-plugin`](https://github.com/github/copilot-advanced-security-plugin) ("The official GitHub Copilot Advanced Security plugin", owned by the `github` org) and `build-perf-cpp`/`spark` inside [`github/copilot-plugins`](https://github.com/github/copilot-plugins) — but checked against the actual [agent-plugins.org 1.0.0 schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json) (`required: ["$schema", "name"]`, `additionalProperties: false`), none of them qualify: they omit the required `$schema` field, their `name` values contain `/` (disallowed by the schema's name pattern), and they declare `skills`/`mcpServers`/`hooks` directly as top-level properties, which the schema doesn't list and explicitly forbids via `additionalProperties: false` (the spec requires such data to live under a namespaced `extensions.<reverse-domain>` object instead). This is GitHub's own native "Copilot Plugin" manifest format — conceptually similar, schema-incompatible, and also not what its own directory-layout convention (`.github/plugin/plugin.json` rather than plugin-root) matches either. The one genuinely conformant `plugin.json` example found in GitHub's orbit is in [`github/awesome-copilot`](https://github.com/github/awesome-copilot) (e.g. `plugins/awesome-copilot/plugin.json`, which declares `$schema` correctly and nests its custom fields under `extensions.com.github.awesome-copilot`) — but that repo's own README states it is "sourced from third-party developers" ("Community-contributed instructions, agents, skills, and configurations..."), so it fails the authorship bar instead. No entry currently clears both bars at once.

**A2A agents**: none found. No `agent_card.json`-conformant agent published by GitHub was located.
