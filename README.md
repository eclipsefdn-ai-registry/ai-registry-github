# AI Registry — GitHub (Inferred)

> **Inferred vendor repository.** This repo is maintained by the [AI Registry](https://github.com/eclipsefdn-ai-registry/ai-registry-core) project, not by GitHub. It pre-seeds the registry with GitHub's official MCP server, its agent-plugins.org plugin, and Agent Skills GitHub publishes for its products.
>
> *This entry is based solely on information published through GitHub's official public channels. GitHub has not endorsed, approved or validated this listing, and is not necessarily participating in the AI Registry.*

## What this repo contains

**MCP server**: [`github/github-mcp-server`](https://github.com/github/github-mcp-server) — "GitHub's official MCP Server" per its own repo description, owned by the verified `github` GitHub org, and live in the official MCP registry as `io.github.github/github-mcp-server`. Registry-listed, so no `metadata` fallback is needed. A generic `config` (remote `http`, `https://api.githubcopilot.com/mcp/` with a bearer-token header) is included anyway — the server's own README documents this remote endpoint as the recommended, host-agnostic connection method (VS Code, Claude Desktop, Cursor, Windsurf, Copilot CLI, Codex, etc. all connect the same way), so it doubles as the canonical config other vendors' `installConfigs` entries for this same `serverId` can request via `"config": "derived"` instead of repeating it.

**Agent Skills**:

- `spark-app-template`, from [`github/copilot-plugins`](https://github.com/github/copilot-plugins) at `plugins/spark/skills/spark-app-template`. `copilot-plugins` is GitHub's own marketplace repo (owned by `github`, described in its README as "the official GitHub Copilot plugins collection", `marketplace.json` owner is `GitHub <copilot@github.com>`). Most of its bundled plugins are explicitly attributed to Microsoft in that same `marketplace.json` (`workiq`, `fabric-*`, `power-*`, `cpp-language-server`, `build-perf-cpp` — the last one authored by two named Microsoft engineers even though it lives in this repo). The `spark` entry carries no such third-party author, its content matches [GitHub Spark](https://github.com/features/spark) (GitHub's own AI app-building product), and its commit history shows it was authored/reviewed directly by GitHub staff (e.g. `JasonEtco`, whose public profile lists `company: GitHub`) committing straight to `main`. On that basis it's included; `build-performance-analysis`, the other skill in this repo (nested under the Microsoft-attributed `build-perf-cpp` plugin), is excluded.

- `io.github.github-actions-migrations` — 11 skills from [`github/actions-migrations-via-copilot`](https://github.com/github/actions-migrations-via-copilot) (`plugin/skills/*`, as an explicit list): CI/CD migration guidance to GitHub Actions from Jenkins, Azure DevOps, CircleCI, GitLab, Travis, Bamboo, Bitbucket and Drone, plus `migration-core`, `actionlint` and `reusable-workflow-patterns`. The manifest names "GitHub Professional Services" as author, and the content is portable CI translation material with nothing Copilot-specific in it.
- `io.github.github-advanced-security` — `secret-scanning` and `dependency-scanning` from [`github/copilot-advanced-security-plugin`](https://github.com/github/copilot-advanced-security-plugin) ("The official GitHub Copilot Advanced Security plugin"). The skills sit at the canonical root `skills/`; they drive the GitHub MCP Server's secret scanning and Dependabot tools against the user's own repository.
- `io.github.github/gh-stack` — `skills/gh-stack` from [`github/gh-stack`](https://github.com/github/gh-stack) ("GitHub Stacked PRs"), documenting the public `gh stack` CLI extension; frontmatter `metadata.author: github`.

Skills are listed as explicit paths rather than globs, so later additions to those directories are reviewed before they are published.

**Agent Plugin**: `io.github.github/github-mcp-server` — the agent-plugins.org-conformant `plugin.json` at `agent-plugin/` in [`github/github-mcp-server`](https://github.com/github/github-mcp-server), packaging the MCP server above.

**Other GitHub plugins — considered and excluded**: GitHub ships `plugin.json` files that look like agent-plugins.org manifests — e.g. [`github/copilot-advanced-security-plugin`](https://github.com/github/copilot-advanced-security-plugin) ("The official GitHub Copilot Advanced Security plugin", owned by the `github` org) and `build-perf-cpp`/`spark` inside [`github/copilot-plugins`](https://github.com/github/copilot-plugins) — but checked against the actual [agent-plugins.org 1.0.0 schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json) (`required: ["$schema", "name"]`, `additionalProperties: false`), none of them qualify: they omit the required `$schema` field, their `name` values contain `/` (disallowed by the schema's name pattern), and they declare `skills`/`mcpServers`/`hooks` directly as top-level properties, which the schema doesn't list and explicitly forbids via `additionalProperties: false` (the spec requires such data to live under a namespaced `extensions.<reverse-domain>` object instead). This is GitHub's own native "Copilot Plugin" manifest format — conceptually similar, schema-incompatible, and also not what its own directory-layout convention (`.github/plugin/plugin.json` rather than plugin-root) matches either. The one genuinely conformant `plugin.json` example found in GitHub's orbit is in [`github/awesome-copilot`](https://github.com/github/awesome-copilot) (e.g. `plugins/awesome-copilot/plugin.json`, which declares `$schema` correctly and nests its custom fields under `extensions.com.github.awesome-copilot`) — but that repo's own README states it is "sourced from third-party developers" ("Community-contributed instructions, agents, skills, and configurations..."), so it fails the authorship bar instead. None of these clears both bars at once. Also excluded:

- `github/spec-kit-copilot` — its `speckit-*` skills are the contained skills of a repo-root Copilot `plugin.json` and are bound to that plugin ("Because this is the Copilot plugin…"), so they are tool packaging, not a standalone catalog.
- `github/replica` `.github/extensions/replica-prototype` (checked 2026-10-16) — a schema-valid agent-plugins.org manifest, but its only content is a `com.github.copilot` client extension, with no `skills/` and no `mcp.json`. In any client other than Copilot it would install as an empty package. Revisit if it gains portable content.

**A2A agents**: none found. No `agent_card.json`-conformant agent published by GitHub was located.
